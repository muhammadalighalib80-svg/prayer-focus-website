# Prayer Focus — Static Website

Official static website for **Prayer Focus** (Android App: `com.prayerfocus.app`), configured and ready for instant deployment on [Vercel](https://vercel.com).

---

## 📁 Repository Structure

```
├── index.html        # Mobile-friendly homepage with branding, intro, features & support
├── privacy.html      # Official Privacy Policy (verified, 100% offline claims, zero tracking)
├── app-ads.txt       # Plain-text Google AdMob publisher verification file
├── robots.txt        # Crawler directives permitting AdMob and search engine indexers
├── vercel.json       # Vercel configuration for clean URLs, MIME types & security headers
├── favicon.svg       # Vector app icon favicon
└── assets/
    └── icon.svg      # Official Prayer Focus vector logo icon
```

---

## 🚀 How to Deploy on Vercel

1. Log in to [vercel.com](https://vercel.com).
2. Click **"Add New..."** ➔ **"Project"**.
3. Import this repository: `prayer-focus-website`.
4. Keep the default settings (**Framework Preset**: `Other`, **Root Directory**: `./`).
5. Click **Deploy**.
6. Your website is live in seconds!

---
